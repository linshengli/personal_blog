# Agent Evaluation STAR 总结

> 调研日期：2026-03-01

---

## Situation（背景 + 痛点）

随着 LLM 驱动的 Agent 系统在客服、编程、数据分析等场景的广泛应用，如何科学评估 Agent 能力成为行业瓶颈。传统 LLM 评估（如 MMLU）仅测语言知识，无法衡量工具使用、多步规划、环境交互等 Agent 核心能力。企业面临"上线前不知道效果，上线后不知道问题在哪"的困境。

**核心痛点：**
1. 基准测试与生产场景脱节
2. 评估周期长（周级），无法支持快速迭代
3. 黑盒评估，无法诊断问题根因
4. 成本高昂（人类评估$500-2000/千任务）
5. 缺乏统一的评估标准和工具链

---

## Task（核心问题）

Agent 评估需同时回答五个问题：

| 问题 | 关注点 | 典型指标 |
|------|--------|---------|
| **能力边界** | Agent 能完成哪些任务？成功率多少？ | 任务完成率 (TSR) |
| **效率** | 完成任务需要多少步、多少时间、多少成本？ | 平均步数、延迟、$/任务 |
| **可靠性** | 面对边界情况和对抗输入是否稳定？ | 鲁棒性分数 (RS) |
| **安全性** | 是否存在 Reward Hacking、Prompt 注入等风险？ | 安全违规率 |
| **可解释性** | 决策过程是否可追溯、可审计？ | 轨迹完整性 |

**约束条件：**
- 成本可控（<$500/月 for 中型项目）
- 评估周期短（<24 小时完成千任务评估）
- 结果可复现、可对比
- 支持持续评估（集成 CI/CD）

---

## Action（主流方案）

技术演进经历三个阶段：

### 阶段 1：基准测试时代（2023）
**代表工具**：AgentBench、WebArena、GAIA、SWE-bench

**核心思想**：在标准化环境中运行 Agent，统计任务完成率

**局限性**：
- 环境搭建复杂
- 运行耗时（小时级）
- 与生产场景有差距

### 阶段 2：可观测性时代（2024-2025）
**代表工具**：LangSmith、Arize Phoenix、AgentOps、TruLens

**核心思想**：记录完整执行轨迹，支持实时诊断

**关键突破**：
- Tracing 技术：LLM 调用、工具使用、状态变化全记录
- Dashboard 可视化：延迟、成本、错误率实时监控
- 与开发工具链集成（VS Code、LangChain）

### 阶段 3：混合评估时代（2026-）
**代表方案**：单元测试 → 基准测试 → LLM 评判 → 人类评估的分层体系

**核心思想**：分层过滤，高效利用资源

| 层级 | 方案 | 速度 | 成本 | 可靠性 |
|------|------|------|------|--------|
| L1 | 单元测试 | 秒级 | $ | 高（确定性） |
| L2 | 基准测试 | 小时级 | $$ | 高（标准化） |
| L3 | LLM 评判 | 分钟级 | $$ | 中 |
| L4 | 人类评估 | 天级 | $$$$ | 极高 |

## Result（效果 + 建议）

### 当前成果

| 指标 | 2023 年 | 2026 年 | 改进 |
|------|--------|--------|------|
| 评估周期 | 1-2 周 | <24 小时 | 100x 加速 |
| 成本/千任务 | $1000+ | $50-200 | 5-20x 降低 |
| 工具成熟度 | 早期 | 成熟 | 生态完善 |
| 标准化程度 | 无共识 | 初步标准 | 行业协作 |

### 现存局限

1. **多 Agent 协作评估**：仍处于早期，缺乏标准基准
2. **真实世界评估**：In-the-Wild 方法论尚未统一
3. **形式化验证**：工具链不成熟，学习曲线陡峭
4. **评估偏差**：LLM-as-a-Judge 的系统性偏差仍未完全解决

### 实操建议

| 场景 | 推荐方案 | 工具组合 | 月成本 |
|------|---------|---------|--------|
| **个人项目** | 单元测试 + LLM 评判 | DeepEval + LangSmith 免费 | $0-25 |
| **中型生产** | 追踪 + 抽样基准 | Phoenix + AgentBench 子集 | $200-500 |
| **企业级** | 混合评估 | LangSmith + Scale + 基准 | $2000+ |
| **学术研究** | 基准测试 | AgentBench + WebArena | $0-100 |
