### 1.2 LangChain

**概况：**
- **发布年份**: 2022
- **GitHub Stars**: 90,000+
- **定位**: 最流行的 LLM 应用开发框架
- **语言**: Python, JavaScript/TypeScript

**核心特性：**
```python
from langchain.agents import AgentExecutor, create_tool_calling_agent
from langchain_openai import ChatOpenAI
from langchain_community.tools import DuckDuckGoSearchRun

# 初始化组件
llm = ChatOpenAI(model="gpt-4")
tools = [DuckDuckGoSearchRun()]

# 创建 Agent
agent = create_tool_calling_agent(llm, tools)
executor = AgentExecutor(agent=agent, tools=tools)

# 执行
response = executor.invoke({"input": "今天的新闻"})
```

### 1.3 AutoGen

**概况：**
- **发布年份**: 2023
- **开发者**: Microsoft Research
- **GitHub Stars**: 50,000+
- **定位**: 多 Agent 对话框架

**核心特性：**
```python
from autogen import AssistantAgent, UserProxyAgent

# 配置
config_list = [{"model": "gpt-4", "api_key": "xxx"}]

# 创建 Agent
assistant = AssistantAgent(
    name="assistant",
    llm_config={"config_list": config_list}
)

user_proxy = UserProxyAgent(
    name="user_proxy",
    human_input_mode="NEVER",
    code_execution_config={"work_dir": "coding"}
)

# 启动对话
user_proxy.initiate_chat(
    assistant,
    message="帮我分析这个数据集"
)
```

### 1.4 CrewAI

**概况：**
- **发布年份**: 2023
- **GitHub Stars**: 30,000+
- **定位**: 基于角色的多 Agent 协作框架

**核心特性：**
```python
from crewai import Agent, Task, Crew

# 定义角色
researcher = Agent(
    role="高级研究员",
    goal="进行深入的市场研究",
    backstory="你是一位经验丰富的市场分析师",
    verbose=True
)

writer = Agent(
    role="技术作家",
    goal="撰写清晰的技术文档",
    backstory="你有 10 年技术写作经验",
    verbose=True
)

# 定义任务
research_task = Task(
    description="研究 AI Agent 市场趋势",
    agent=researcher
)

write_task = Task(
    description="根据研究结果撰写报告",
    agent=writer
)

# 创建 Crew 并执行
crew = Crew(agents=[researcher, writer], tasks=[research_task, write_task])
result = crew.kickoff()
```

### 1.5 LlamaIndex

**概况：**
- **发布年份**: 2022
- **GitHub Stars**: 35,000+
- **定位**: RAG 和数据连接框架

**核心特性：**
```python
from llama_index.core import VectorStoreIndex, SimpleDirectoryReader
from llama_index.agent import ReActAgent
from llama_index.llms.openai import OpenAI

# 加载文档
documents = SimpleDirectoryReader("./data").load_data()

# 创建索引
index = VectorStoreIndex.from_documents(documents)

# 创建查询引擎
query_engine = index.as_query_engine()

# 创建 Agent
llm = OpenAI(model="gpt-4")
agent = ReActAgent.from_tools(
    tools=[query_engine.as_tool()],
    llm=llm
)

response = agent.chat("文档中关于 RAG 的内容是什么？")
```

### 3.4 自定义 Agent 示例

# LangChain 自定义 Agent
from langchain.agents import AgentExecutor, BaseSingleActionAgent

class CustomAgent(BaseSingleActionAgent):
    """自定义 Agent 实现"""

    def plan(self, intermediate_steps, **kwargs):
        # 自定义规划逻辑
        pass

    def create_agent_runnable(self):
        return RunnableLambda(self.plan)

# AutoGen 自定义 Agent
from autogen import ConversableAgent

class MyCustomAgent(ConversableAgent):
    """自定义 ConversableAgent"""

    def __init__(self, name, **kwargs):
        super().__init__(name, **kwargs)
        self.register_reply([str, dict], self.custom_reply)

    def custom_reply(self, message, sender, config):
        # 自定义回复逻辑
        return True, {"content": "Custom response"}

## 4. 多 Agent 协作支持

### 4.1 协作模式对比

| 模式 | LangChain | AutoGen | CrewAI |
|------|-----------|---------|--------|
| **串行** | ✅ Chains | ✅ 顺序对话 | ✅ 顺序任务 |
| **并行** | ⚠️ 需自定义 | ✅ 群聊 | ⚠️ 有限 |
| **层级** | ⚠️ 需自定义 | ⚠️ 需自定义 | ✅ 内置 |
| **市场机制** | ❌ | ⚠️ 需自定义 | ❌ |

### 4.2 AutoGen 群聊模式

```python
from autogen import GroupChat, GroupChatManager

# 创建多个 Agent
agent_a = AssistantAgent("agent_a", llm_config=llm_config)
agent_b = AssistantAgent("agent_b", llm_config=llm_config)
agent_c = AssistantAgent("agent_c", llm_config=llm_config)

# 创建群聊
groupchat = GroupChat(
    agents=[agent_a, agent_b, agent_c],
    messages=[],
    max_round=10
)

# 创建群聊管理器
manager = GroupChatManager(
    groupchat=groupchat,
    llm_config=llm_config
)

# 启动群聊
UserProxyAgent.initiate_chat(
    manager,
    message="讨论这个项目的架构设计"
)
```

### 4.3 CrewAI 层级协作

```python
from crewai import Crew, Agent, Task, Process

# 定义层级
ceo = Agent(
    role="CEO",
    goal="制定战略决策",
    verbose=True
)

cto = Agent(
    role="CTO",
    goal="技术架构设计",
    verbose=True
)

cfo = Agent(
    role="CFO",
    goal="财务规划",
    verbose=True
)

# 层级流程任务
task1 = Task(description="制定年度目标", agent=ceo)
task2 = Task(description="技术规划", agent=cto)
task3 = Task(description="预算规划", agent=cfo)

# 使用层级流程
crew = Crew(
    agents=[ceo, cto, cfo],
    tasks=[task1, task2, task3],
    process=Process.hierarchical,  # 层级模式
    manager_llm=llm  # 指定协调者 LLM
)
```

### 5.2 LangChain 工具生态

```python
from langchain_community.tools import (
    # 搜索工具
    DuckDuckGoSearchRun,
    GoogleSearchRun,

    # 代码执行
    PythonREPLTool,

    # 数据库
    SQLDatabaseToolkit,

    # API 工具
    RequestsGetTool,
    RequestsPostTool,

    # 文件操作
    FileReadTool,
    FileWriteTool,

    # Wolfram Alpha
    WolframAlphaQueryRun,
)

# 使用装饰器快速创建工具
from langchain.tools import tool

@tool
def calculate_bmi(height: float, weight: float) -> float:
    """计算 BMI 指数"""
    return weight / (height ** 2)
```

### 5.3 工具注册示例

```python
# AutoGen 工具注册
def calculate(expression: str) -> str:
    """计算数学表达式"""
    try:
        result = eval(expression)
        return str(result)
    except Exception as e:
        return f"Error: {e}"

# 注册到 Agent
agent.register_function(
    function_map={
        "calculate": calculate
    }
)

# CrewAI 工具定义
from crewai_tools import BaseTool

class CustomTool(BaseTool):
    name: str = "我的工具"
    description: str = "工具描述"

    def _run(self, argument: str) -> str:
        # 工具实现
        return f"处理结果：{argument}"
```

## 7. 适用场景分析

### 7.1 场景推荐矩阵

```
                    多 Agent 协作需求
                    低 ←────────────→ 高
                ┌───────────┬───────────┐
            低  │ LlamaIndex│ LangChain │
               │ (RAG 为主)  │ (通用)    │
RAG 需求        ├───────────┼───────────┤
            高  │ LangChain │ AutoGen   │
               │ (全面)    │ (强协作)   │
                └───────────┴───────────┘
```

### 7.2 具体场景推荐

| 场景 | 首选框架 | 备选框架 | 理由 |
|------|---------|---------|------|
| **RAG 问答系统** | LlamaIndex | LangChain | 数据连接丰富 |
| **多 Agent 协作** | AutoGen | CrewAI | 对话机制成熟 |
| **快速原型开发** | LangChain | CrewAI | 工具生态完善 |
| **生产部署** | LangChain | Haystack | 企业级支持 |
| **角色扮演应用** | CrewAI | CAMEL | 角色抽象好 |
| **代码生成任务** | MetaGPT | AutoGen | 软件工程优化 |
| **可视化需求** | Flowise | LangChain | UI 支持好 |
