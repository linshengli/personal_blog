# 第一部分：概念剖析

[完整内容见 agent-memory-concept.md](./agent-memory-concept.md)

## 核心要点速览

- **定义**：赋予 LLM Agent 跨交互持久化信息存储与检索能力的系统
- **五类记忆**：工作记忆（上下文窗口）、情景记忆（历史交互）、语义记忆（知识事实）、程序性记忆（技能模式）、联想记忆（关联图谱）
- **核心公式**：检索得分 = α·语义相似度 + β·时间新近性 + γ·记忆重要性
- **关键区分**：记忆 ≠ RAG（动态 vs 静态）、≠ 上下文窗口（持久 vs 临时）、≠ 向量数据库（系统 vs 存储后端）

# 第三部分：方案对比

[完整内容见 agent-memory-analysis.md](./agent-memory-analysis.md)

## 核心要点速览

- **六种方案**：纯上下文窗口 | 向量存储 | 图谱记忆 | 层次化管理 | 摘要压缩 | 混合架构
- **选型速查**：
  - 快速原型 → 上下文窗口 + 摘要
  - 生产通用 → Mem0（向量存储）
  - 关系推理 → Zep/Graphiti（图谱）
  - 深度交互 → Letta（层次化）
  - 大型系统 → 混合架构
- **七大陷阱**：存一切综合症、忽视记忆冲突、过度依赖向量相似度、记忆注入无防护、摘要幻觉、冷启动空记忆、基准幻觉

# 第四部分：精华整合

[完整内容见 02-The-All-in-One.md](./02-The-All-in-One.md)

## The One 公式

$$
\text{Agent Memory} = \text{持久化存储} + \text{智能检索} + \text{主动遗忘} - \text{上下文窗口税}
$$

## 一句话

> 就像你的大脑会自动记住重要的事、忘掉无关的细节一样，Agent Memory 让 AI 也拥有了这种"选择性记忆"的能力。

## 关键洞察

Letta 的简单文件系统 Agent 在 LoCoMo 上达到 74%，超过 Mem0 的 68.5%——这暴露了专用记忆框架的核心价值可能不在检索准确率，而在成本控制、延迟优化和系统化管理。
