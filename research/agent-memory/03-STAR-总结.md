# Agent Memory（智能体记忆）STAR 总结

> 调研日期：2026-02-28

---

## STAR 方法论总结

### Situation（背景 + 痛点）

LLM 驱动的 Agent 面临核心矛盾：**固定上下文窗口 vs 无限交互历史**。传统方案如 RAG 仅支持只读检索，无法积累 Agent 自身经验；纯会话历史截断导致重要信息丢失；跨会话个性化无从谈起。随着 Agent 应用从原型走向生产，记忆成为制约长期交互质量的瓶颈。

**核心挑战**：
- 如何在有限 token 预算内注入最相关的历史信息？
- 如何区分"需要记住的"和"可以遗忘的"？
- 如何平衡检索精度、延迟和成本？

---

### Task（核心问题）

在以下约束条件下实现跨会话持久化记忆：

| 约束 | 目标值 |
|------|--------|
| 检索延迟 | < 100ms (P95) |
| 记忆精度 | > 90% (Recall@10) |
| 记忆容量 | 支持百万级条目 |
| 遗忘机制 | 自动清除低价值记忆 |
| 隐私隔离 | 多租户数据不越界 |

---

### Action（主流方案）

技术演进经历三个关键阶段：

**阶段 1：奠基（2023）**
- Generative Agents 提出 Recall/Archival 二分法
- MemGPT 引入分层记忆 + 虚拟上下文管理

**阶段 2：标准化（2024）**
- LangChain Memory 模块统一接口
- Zep、Mem0 等专用记忆服务兴起

**阶段 3：成熟（2025-2026）**
- 统一记忆层（Mem0）成为基础设施
- 图记忆（A-Mem）增强推理能力
- 安全防御（A-MemGuard）应对投毒攻击
- r3 benchmark 建立标准化评测

**核心突破**：将人类记忆的"编码→巩固→提取→遗忘"机制工程化为可落地的系统架构。

---

### Result（效果 + 建议）

**当前最优水平**（r3 benchmark, 2025）：
- Recall@10 = 87%
- P95 延迟 = 85ms
- 高优先级记忆保留 = 6.2 小时
- 任务偏移率 < 5%

**选型建议矩阵**：

| 场景 | 推荐方案 | 成本量级 |
|------|---------|---------|
| 原型验证 | 短期记忆 + 摘要 | $ |
| 中型生产 | 向量检索 + 持久对话 | $$ |
| 大型系统 | 混合分层 + 知识图谱 | $$$ |

**2026 年趋势**：统一记忆层标准化、安全防御标配化、边缘记忆兴起、多 Agent 记忆共享。

---

## 理解确认

**问题**：为什么 RAG 不等于 Agent Memory？

**答案要点**：
1. RAG 是只读的外部知识检索，Agent Memory 支持读写和自主更新
2. RAG 的知识来自人工导入的文档，Agent Memory 的知识来自 Agent 自身经验积累
3. RAG 没有遗忘机制，Agent Memory 会主动遗忘低价值信息

**关键洞察**：RAG 是"开卷考试"（查外部资料），Agent Memory 是"闭卷考试 + 记笔记"（积累自身经验）。
