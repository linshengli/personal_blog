## 核心结论速览

### The One 公式

$$
\text{Agent Sandbox} = \underbrace{\text{隔离环境}}_{\text{容器/VM}} + \underbrace{\text{资源限制}}_{\text{CPU/内存/网络}} + \underbrace{\text{安全审查}}_{\text{Pre/Post 检查}} - \underbrace{\text{逃逸风险}}_{\text{需持续监控}}
$$

### 选型建议

| 场景 | 推荐方案 |
|------|---------|
| 开发测试 | Docker |
| AI Agent | E2B / OpenHands |
| 多租户 | gVisor / Firecracker |
| 企业级 | Kata / Firecracker |
| 前端演示 | Browser Sandbox |

### 关键指标

| 指标 | 当前水平 |
|------|---------|
| 启动延迟 | <500ms |
| 性能损耗 | <15% |
| 隔离强度 | 阻止 99%+ 已知逃逸 |
