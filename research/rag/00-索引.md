## 核心结论速览

### The One 公式

$$
\text{RAG} = \underbrace{\text{检索}}_{\text{找信息}} + \underbrace{\text{增强}}_{\text{建上下文}} + \underbrace{\text{生成}}_{\text{答问题}} - \underbrace{\text{幻觉}}_{\text{需抑制}}
$$

### 选型建议

| 场景 | 推荐方案 |
|------|---------|
| 快速原型 | Flowise / Dify |
| 数据密集型 | LlamaIndex |
| 企业级 | LangChain / Haystack |
| 知识推理 | GraphRAG |
| 中文场景 | Dify / LangChain-Chatchat |

### 关键指标

| 指标 | 当前水平 |
|------|---------|
| 答案准确率 | 80-90% |
| 幻觉率 | <10% |
| 检索延迟 | <100ms |
