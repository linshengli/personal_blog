## 1. 概念剖析

### 1.1 什么是 Agent Loop

**Agent Loop（智能体循环）** 是指 AI Agent 执行任务时的核心循环机制，它定义了 Agent 如何感知环境、进行推理、采取行动并获取反馈的完整过程。

### 1.2 感知 - 思考 - 行动循环 (Perceive-Think-Act Cycle)

```
┌─────────────────────────────────────────────────────────────┐
│                    Agent Loop Architecture                   │
│                                                              │
│    ┌──────────┐      ┌──────────┐      ┌──────────┐        │
│    │ Perceive │ ───► │  Think   │ ───► │   Act    │        │
│    │  感知    │      │  思考    │      │  行动    │        │
│    └────┬─────┘      └────┬─────┘      └────┬─────┘        │
│         │                 │                 │               │
│         │                 │                 │               │
│         └─────────────────┴─────────────────┘               │
│                           │                                 │
│                           ▼                                 │
│                    ┌─────────────┐                          │
│                    │ Environment │                          │
│                    │    环境     │                          │
│                    └─────────────┘                          │
└─────────────────────────────────────────────────────────────┘
```

**循环阶段详解：**

| 阶段 | 输入 | 处理 | 输出 |
|------|------|------|------|
| **感知 (Perceive)** | 用户输入、环境状态、工具返回 | 信息收集与解析 | 上下文表示 |
| **思考 (Think)** | 上下文、目标、记忆 | 推理、规划、决策 | 行动计划 |
| **行动 (Act)** | 行动计划 | 工具调用、API 请求 | 执行结果 |

### 1.3 Agent Loop 的核心要素

```python
class AgentLoop:
    """Agent 循环抽象表示"""

    def __init__(self):
        self.state = AgentState()
        self.history = []
        self.max_iterations = 10

    def run(self, task: str) -> Result:
        """执行完整循环"""
        self.state.set_goal(task)

        while not self.is_complete() and not self.is_exhausted():
            # 1. 感知
            context = self.perceive()

            # 2. 思考
            plan = self.think(context)

            # 3. 行动
            action = self.decide(plan)
            result = self.act(action)

            # 4. 更新状态
            self.update(result)

        return self.finalize()
```

## 2. ReAct 模式

### 2.1 ReAct 概述

**ReAct (Reasoning + Acting)** 是一种将推理与行动相结合的 Agent 范式，由 Princeton 大学研究人员在 2022 年提出。

**核心思想：** 在执行每个动作之前，先进行显式的推理思考。

### 2.2 ReAct 格式

```
Thought: 我需要先搜索关于 X 的信息
Action: search[query="X"]
Observation: [搜索结果...]

Thought: 根据搜索结果，我需要进一步了解 Y
Action: search[query="Y"]
Observation: [搜索结果...]

Thought: 现在我有足够的信息来回答问题了
Final Answer: [综合回答]
```

### 2.3 ReAct 实现示例

```python
from typing import List, Dict, Optional
from dataclasses import dataclass

@dataclass
class ReActStep:
    thought: str
    action: Optional[str]
    observation: Optional[str]
    final_answer: Optional[str]

class ReActAgent:
    def __init__(self, llm, tools: Dict[str, callable]):
        self.llm = llm
        self.tools = tools
        self.steps: List[ReActStep] = []

    def run(self, question: str, max_steps: int = 5) -> str:
        prompt = self._build_prompt(question)

        for _ in range(max_steps):
            response = self.llm.generate(prompt)

            # 解析响应
            thought = self._extract_thought(response)
            action = self._extract_action(response)
            final_answer = self._extract_final_answer(response)

            if final_answer:
                return final_answer

            # 执行动作
            observation = self._execute_action(action)

            # 添加历史记录
            self.steps.append(ReActStep(
                thought=thought,
                action=action,
                observation=observation,
                final_answer=None
            ))

            # 更新提示
            prompt += self._format_step(thought, action, observation)

        return "Max steps reached without conclusion"

    def _build_prompt(self, question: str) -> str:
        return f"""Answer the following question by reasoning step by step.
You have access to these tools:
- search[query]: Search for information
- calculate[expression]: Perform calculation

Question: {question}

Thought: """

    def _execute_action(self, action: str) -> str:
        # 解析并执行动作
        tool_name, args = self._parse_action(action)
        if tool_name in self.tools:
            return str(self.tools[tool_name](args))
        return "Unknown tool"
```

### 2.4 ReAct vs 其他模式

| 模式 | 特点 | 优点 | 缺点 |
|------|------|------|------|
| **ReAct** | 思考 + 行动交替 | 可解释性强、错误易发现 | 步骤多、耗时长 |
| **CoT** | 纯推理 | 逻辑连贯 | 无法获取外部信息 |
| **Act-only** | 直接行动 | 快速 | 错误率高、难调试 |

### 3.1 PER 循环模型

```
┌─────────────────────────────────────────────────────────────┐
│                  Plan-Execute-Reflect Loop                   │
│                                                              │
│         ┌─────────────────────────────────────────┐         │
│         │                                         │         │
│         ▼                                         │         │
│    ┌─────────┐    ┌─────────┐    ┌─────────┐     │         │
│    │  Plan   │───►│ Execute │───►│ Reflect │─────┘         │
```

### 3.2 规划阶段

**任务分解策略：**

```python
class TaskPlanner:
    """任务规划器"""

    def decompose(self, task: str) -> List[SubTask]:
        """将复杂任务分解为可执行的子任务"""

        prompt = f"""Decompose the following task into executable sub-tasks:

Task: {task}

Return sub-tasks in order of execution. Each sub-task should be:
- Specific and actionable
- Independent where possible
- Ordered by dependency
"""
        return self.llm.generate(prompt)

    def create_dependency_graph(self, tasks: List[SubTask]) -> DependencyGraph:
        """创建任务依赖图"""
        graph = DependencyGraph()

        for task in tasks:
            graph.add_node(task)
            deps = self._find_dependencies(task, tasks)
            for dep in deps:
                graph.add_edge(dep, task)

        return graph
```

### 3.3 执行阶段

```python
class TaskExecutor:
    """任务执行器"""

    def __init__(self, planner: TaskPlanner, tools: Dict):
        self.planner = planner
        self.tools = tools
        self.results = {}

    def execute_plan(self, plan: Dict) -> ExecutionResult:
        """执行规划的任务"""
        graph = plan.create_dependency_graph()
        order = graph.topological_sort()

        for task_id in order:
            task = plan.get_task(task_id)

            # 检查依赖
            if not self._dependencies_satisfied(task):
                raise ExecutionError(f"Dependencies not satisfied for {task_id}")

            # 执行任务
            result = self._execute_task(task)
            self.results[task_id] = result

            # 检查中间结果
            if result.failed:
                return self._handle_failure(task, result)

        return ExecutionResult(
            success=True,
            results=self.results
        )

    def _execute_task(self, task: SubTask) -> TaskResult:
        tool = self.tools.get(task.tool)
        if not tool:
            return TaskResult.failed(f"Unknown tool: {task.tool}")

        try:
            output = tool(**task.parameters)
            return TaskResult(success=True, output=output)
        except Exception as e:
            return TaskResult.failed(str(e))
```

### 3.4 反思阶段

**反思的类型：**

| 类型 | 时机 | 目的 |
|------|------|------|
| **执行后反思** | 每个动作执行后 | 验证结果是否符合预期 |
| **阶段性反思** | 完成一组子任务后 | 评估进度和方向 |
| **最终反思** | 任务完成后 | 总结与学习 |

**反思实现：**
```python
class Reflector:
    """反思器"""

    def __init__(self, llm):
        self.llm = llm

    def reflect_on_action(self, action: str, result: str, expected: str) -> Reflection:
        """反思单个动作"""
        prompt = f"""Reflect on the following action:

Action: {action}
Expected: {expected}
Actual Result: {result}

Questions to answer:
1. Did the action achieve the expected outcome?
2. If not, what went wrong?
3. What should be done differently next time?
"""
        response = self.llm.generate(prompt)
        return self._parse_reflection(response)

    def reflect_on_plan(self, original_plan: List, executed: List, outcome: str) -> PlanRevision:
        """反思整个计划"""
        prompt = f"""Compare the original plan with actual execution:

Original Plan: {original_plan}
Executed: {executed}
Final Outcome: {outcome}

Analyze:
1. Were there any unnecessary steps?
2. Were there missing steps?
3. How can the planning be improved?
"""
        return self.llm.generate(prompt)
```

## 4. 迭代优化机制

### 4.1 自改进循环

```
┌─────────────────────────────────────────────────────────────┐
│              Self-Improvement Loop                          │
│                                                              │
│   Initial ──► Execute ──► Evaluate ──► Identify Issues      │
│      ▲                                        │             │
│      │                                        ▼             │
│      │                                  Generate Fixes      │
│      │                                        │             │
│      │                                        ▼             │
│      └────────────────────────────────── Apply Changes       │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

### 4.2 迭代优化策略

```python
class IterativeOptimizer:
    """迭代优化器"""

    def __init__(self, agent, evaluator, max_iterations: int = 5):
        self.agent = agent
        self.evaluator = evaluator
        self.max_iterations = max_iterations

    def optimize(self, task: str, initial_response: str) -> str:
        """迭代优化响应"""
        current = initial_response

        for iteration in range(self.max_iterations):
            # 评估当前响应
            evaluation = self.evaluator.evaluate(task, current)

            if evaluation.score >= evaluation.target_score:
                break

            # 生成改进建议
            improvements = self._generate_improvements(
                task, current, evaluation
            )

            # 应用改进
            current = self._apply_improvements(current, improvements)

        return current

    def _generate_improvements(self, task: str, response: str,
                                evaluation: Evaluation) -> List[str]:
        prompt = f"""Task: {task}
Current Response: {response}
Evaluation Feedback: {evaluation.feedback}

Suggest specific improvements to address the issues."""

        return self.agent.llm.generate(prompt).split('\n')
```

### 4.3 反思式学习

```python
class ReflexiveLearner:
    """反思式学习者 - 从经验中学习"""

    def __init__(self):
        self.experience_buffer = []
        self.learned_patterns = {}

    def record_experience(self, experience: Experience):
        """记录经验"""
        self.experience_buffer.append({
            'task_type': experience.task_type,
            'approach': experience.approach,
            'outcome': experience.outcome,
            'success': experience.success,
            'lessons': experience.lessons
        })

    def retrieve_similar(self, task: str) -> List[Experience]:
        """检索相似任务的经验"""
        return [
            exp for exp in self.experience_buffer
            if self._is_similar(task, exp['task_type'])
        ]

    def update_patterns(self, experiences: List[Experience]):
        """从经验中更新模式"""
        for exp in experiences:
            key = exp.task_type
            if key not in self.learned_patterns:
                self.learned_patterns[key] = {
                    'successful': [],
                    'failed': []
                }

            if exp.success:
                self.learned_patterns[key]['successful'].append(exp.approach)
            else:
                self.learned_patterns[key]['failed'].append(exp.approach)
```

## 5. 终止条件与循环控制

### 5.1 终止条件类型

| 条件类型 | 描述 | 实现方式 |
|---------|------|---------|
| **目标达成** | 任务完成 | 结果验证 |
| **最大迭代** | 超过最大循环次数 | 计数器 |
| **超时** | 执行时间超限 | 计时器 |
| **收敛** | 连续迭代无改进 | 变化检测 |
| **资源耗尽** | 预算/配额用完 | 资源监控 |

### 5.2 循环控制实现

```python
class LoopController:
    """循环控制器"""

    def __init__(self,
                 max_iterations: int = 10,
                 max_time_seconds: int = 300,
                 convergence_threshold: int = 3):
        self.max_iterations = max_iterations
        self.max_time = max_time_seconds
        self.convergence_threshold = convergence_threshold

        self.iteration_count = 0
        self.start_time = None
        self.recent_results = []

    def start(self):
        self.start_time = time.time()
        self.iteration_count = 0

    def should_continue(self, current_result) -> bool:
        """判断是否继续循环"""
        self.iteration_count += 1
        self.recent_results.append(current_result)

        # 检查最大迭代
        if self.iteration_count > self.max_iterations:
            return False

        # 检查超时
        if time.time() - self.start_time > self.max_time:
            return False

        # 检查收敛
        if self._has_converged():
            return False

        # 检查目标达成
        if self._goal_achieved(current_result):
            return False

        return True

    def _has_converged(self) -> bool:
        if len(self.recent_results) < self.convergence_threshold:
            return False

        recent = self.recent_results[-self.convergence_threshold:]
        return all(r == recent[0] for r in recent)

    def _goal_achieved(self, result) -> bool:
        # 根据具体任务定义目标达成条件
        return result.is_complete
```

### 5.3 提前终止策略

```python
class EarlyStopping:
    """提前终止策略"""

    def __init__(self, patience: int = 3, min_improvement: float = 0.01):
        self.patience = patience
        self.min_improvement = min_improvement
        self.best_score = float('-inf')
        self.no_improve_count = 0

    def check(self, score: float) -> bool:
        """检查是否应该提前终止"""
        if score > self.best_score + self.min_improvement:
            self.best_score = score
            self.no_improve_count = 0
            return False
        else:
            self.no_improve_count += 1
            return self.no_improve_count >= self.patience
```

## 附录

### A. Agent Loop 设计模式

1. **Chain of Thought (CoT)**: 纯推理链
2. **ReAct**: 推理 + 行动交替
3. **Plan-and-Solve**: 先规划后执行
4. **Self-Refine**: 迭代自改进
5. **Tree of Thoughts**: 多路径探索

### B. 常见问题与解决方案

| 问题 | 症状 | 解决方案 |
|------|------|---------|
| 无限循环 | Agent 反复执行相同动作 | 添加历史检测、最大迭代限制 |
| 过早终止 | 任务未完成就停止 | 改进终止条件判断 |
| 工具滥用 | 过度调用工具 | 添加工具调用成本意识 |
| 上下文溢出 | 历史记录过长 | 实现记忆压缩 |
